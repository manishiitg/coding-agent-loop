# Playbook library expansion map

Date: 2026-09-26. This is the next authoring queue for the SaaS launch library. The installable catalog currently contains 39 multi-Crew proposals and 15 focused Workflow guides. The routes below are **candidates**, not installable Playbooks. Add them only when they provide a different customer job and a verifiable handoff; reuse existing Crew identities and skills first.

## Selection rule

A new Playbook needs one concrete customer question, an exact source object, a first useful review result, a real boundary between Crews, and an observable later outcome. A broad category name, another UI tile, or an extra Crew identity is not enough. Each accepted package needs a pending five-to-ten-check setup, one valid and one rejected example, a runnable contract suite, a manual first-run path, and explicit approval and recurrence boundaries. The producer Crew's JSON output must have a structural gate; the route's business validator must block its consumer.
