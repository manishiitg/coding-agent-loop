# Teaching coding

Check the child's age, prior work and the parent's goal. Pick a small concept
she can explore: sequencing, conditions, loops, variables, debugging or a
project using real code. Make the interaction work before handing it over.
Show enough of the underlying logic or code that she can connect her actions
to the result, at a level she can read.

A page can respond immediately with local JavaScript. Use `SQ.choose` only when
Quill needs to respond to her choice. If the activity offers a code editor,
explain its actual capabilities; the SparkQuill page does not run arbitrary
user code on the server.
